📌 Section 1 Tips

  • Cellular speeds: 2G ~0.1 Mbps, 3G ~2-7 Mbps, 4G LTE ~20-150 Mbps, 5G up to 1+ Gbps real-world.
  • NFC: 13.56 MHz, under 20 cm range. Bluetooth: ~10m. Both are short-range wireless.
  • MDM policies: BYOD = employee-owned device. COPE = company-owned, personal use allowed.
  • Touchscreens: Capacitive = finger or conductive stylus only. Resistive = any object including gloves.
  • USB-PD 3.1: up to 240W over USB-C. Lightning is Apple proprietary reversible 8-pin connector.

📌 Section 2 Tips

  • Port numbers are heavily tested. Memorize all common ports cold before exam day.
  • DHCP DORA: Discover → Offer → Request → Acknowledge. UDP 67 (server) / 68 (client).
  • DNS records: A=IPv4, AAAA=IPv6, CNAME=alias, MX=mail, TXT=SPF/DKIM/DMARC.
  • Wi-Fi channels: 2.4 GHz non-overlapping = 1, 6, 11 only. 5 GHz has many more non-overlapping channels.
  • APIPA 169.254.x.x = DHCP server unreachable. Link-local only, no internet access.
  • Private IP ranges: 10.x/8, 172.16-31.x/12, 192.168.x/16. Not routable on the public internet.

📌 Section 3 Tips

  • Display panels: TN = fastest, IPS = best color/angles, VA = best contrast, OLED = true black (no backlight).
  • RAID: 0 = speed only (no redundancy). 1 = mirror (2 drives). 5 = 3+ drives (1 can fail). 6 = 4+ drives (2 can fail). 10 = 4 drives (best performance + redundancy).
  • Laser printer 7 steps: Processing → Charging → Exposing → Developing → Transferring → Fusing → Cleaning.
  • Memory voltages: DDR3=1.5V, DDR4=1.2V, DDR5=1.1V. DDR4 DIMM=288 pins. SO-DIMM is the laptop form factor.
  • Fuser failure = toner smears. Ghost images = drum not cleaning. Vertical streaks = dirty drum.
  • NVMe vs SATA: NVMe Gen 4 x4 ~7 GB/s. SATA III ~550 MB/s. Always verify M.2 slot type before purchasing.

📌 Section 4 Tips

  • Cloud service models: IaaS = you manage OS and up (AWS EC2). PaaS = you manage apps only (Heroku). SaaS = just use it (Microsoft 365, Google Workspace).
  • Cloud deployment: Public = AWS/Azure/GCP open to all. Private = single org. Hybrid = mix of both. Community = shared between similar orgs (same compliance needs).
  • NIST 5 characteristics: On-demand self-service, Broad network access, Resource pooling, Rapid elasticity, Measured service.
  • Hypervisors: Type 1 (bare-metal) = VMware ESXi, Hyper-V Server, KVM. Type 2 (hosted) = VirtualBox, VMware Workstation, Parallels.
  • VM networking: Bridged = own LAN IP (visible to everyone). NAT = shares host IP (can reach internet, not reachable from outside). Host-only = isolated, host machine only.
  • Containers vs VMs: Containers share host OS kernel (fast, lightweight). VMs have full guest OS (more isolated but heavier).

📌 Section 5 Tips

  • 7-step methodology order matters: Identify → Research → Theory → Test → Plan/Implement → Verify → Document. Document is ALWAYS last.
  • Hardware symptoms: Inaccurate date/time = dead CMOS battery. Swollen caps = failing motherboard. Burning smell = power off immediately. Beep codes = check BIOS manual.
  • Storage: HDD clicking = imminent failure, back up NOW. S.M.A.R.T. warning = replace soon. RAID amber LED = degraded, replace failed drive immediately.
  • Display symptoms: Dim image visible with flashlight = backlight/inverter failure. Burn-in = OLED static image damage. Stuck pixel = permanently lit pixel.
  • Laser printer symptoms: Smeared toner = fuser. Ghost images = drum not cleaning. Vertical lines = scratch on drum. Faded = low toner or transfer roller issue.
  • Network tools: ping = connectivity. tracert = trace hops. ipconfig = show IP config. nslookup = test DNS. netstat = active connections. arp -a = MAC table. pathping = trace + packet loss per hop.
